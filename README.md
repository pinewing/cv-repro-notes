# cv-repro-notes

开源项目复现笔记仓库。用于记录每个复现项目的来源、环境版本、运行步骤、指标对比与排错日志。

## 环境基线

| 项目 | 版本 / 位置 |
| --- | --- |
| 操作系统 | Windows 11 家庭版 中文版 |
| Git | 2.56.1（`D:\Git`） |
| GitHub Desktop | 3.7.0（程序在 `D:\GitHubDesktop`） |
| Python | 按项目 README 单独建 conda/venv 环境，不共用全局 |
| 硬件 | 本机 GPU / 显存以实际为准 |

## 踩坑日志

按「现象 → 原因 → 解决」三段记，方便下次直接搜关键词。

## 提交约定

- 只提交笔记、脚本、配置模板和自写补丁
- 数据集、模型权重（`*.pth` / `*.ckpt` / `*.safetensors`）、虚拟环境目录一律不入库
- 大文件需要版本化时使用 Git LFS，并先在 `.gitattributes` 中声明
