# 复现实现与论文官方实现的差异对比

**对比对象**：论文原文 / 作者官方仓库 / 本复现实现
**证据**：官方源码逐行核对（GCN：`gcn/layers.py`、`models.py`、`train.py`、`utils.py`；GAT：`models/gat.py`、`utils/layers.py`、`execute_cora.py`、`README.md`），本实现数字来自 `results/*.json`

## 1 工程层面

| 维度 | 官方实现 | 本实现 |
| --- | --- | --- |
| 框架 | GCN: TensorFlow 1.x；GAT: TF 1.6 + CUDA 9.0 | PyTorch 2.9.1 CPU，Python 3.12 |
| 图表示 | GCN: scipy 稀疏；GAT: N×N 稠密 + 掩码 | GCN: torch.sparse；GAT: COO 边索引 |
| 运行 | 单次运行、单结果 | `--seeds N` 多种子均值±标准差、`--save-json` 落盘 |
| 依赖 | 需 TF1 与 CUDA，现代环境装不上 | 仅 torch + numpy + scipy + matplotlib |
| 许可 | MIT | 沿用 MIT，逐项标注来源 |

## 2 GCN 逐项对比

| 对比项 | 官方（TF） | 本实现（PyTorch） | 影响 |
| --- | --- | --- | --- |
| 传播算子 | Â = D̃⁻½(A+I)D̃⁻½ | 同一公式 | 一致 |
| 特征归一化 | 行 L1 归一化，保留稀疏 | 行 L1 归一化 | 一致 |
| 网络结构 | 两层，hidden 16 | 两层，hidden 16 | 一致 |
| 偏置 | `bias=False` | 两层带偏置（23 个参数） | 很小 |
| dropout | 稀疏 dropout（只丢非零项，1/keep_prob 缩放） | 稠密标准 dropout | 近似等价 |
| L2 | 仅第一层权重，`∑x²/2` | 仅 `gc1`，`0.5·∑w²`（多含 16 个偏置） | 很小 |
| 优化 | Adam 0.01，200 轮 | 同 | 一致 |
| 早停 | 验证损失高于前 10 轮均值即停 | 同规则 | 一致 |
| 测试口径 | 训练结束参数直接测（单次） | 末轮 + 验证最优双口径 | 口径差 0.2–0.9 点 |
| 参数量 | 22 928（仅权重） | 23 063（含偏置） | +0.6% |

## 3 GAT 逐项对比

| 对比项 | 官方（TF 1.6） | 本实现 | 影响 |
| --- | --- | --- | --- |
| 邻接 | N×N 稠密 + `adj_to_bias`（非邻居加 −1e9） | COO 边索引 + 分段 softmax | 数学等价，内存 O(N²)→O(E) |
| 第二层头数 | `n_heads=[8,1]` 单头输出 | 默认 8 头（`--out-heads 1` 对齐官方） | 实测，方向随数据集变化 |
| 注意力偏置 | `conv1d` 的 f1/f2 带偏置 + 输出 `bias_add` | 无偏置（加偏置使 Cora 82.8→80.8，已回滚） | 负向，已验证 |
| dropout | 输入 + 注意力系数 + 变换后再丢一次 | 输入 + 注意力系数 + 隐层 | 接近 |
| 轮数 | 最多 100 000，patience 100 | 200 轮，patience 100 | 影响早停位置 |
| 测试口径 | 加载验证最优检查点 | 末轮 + 验证最优并报 | 需分列 |
| 残差 | 有开关，Cora 脚本设 False | `--residual`，默认关，实测负收益 | 负向，已验证 |
| 数据增强 | 无 | `--edge-dropout` 训练期丢边 | 本实现新增 |
| 参数量 | ≈92 302（单头、不计卷积偏置） | 95 536（8 头）/ 92 302（单头） | +3.5% |
| 预训练 | 提供 Cora 权重，README 标 84.4% | 不提供，每次现场训练 | 口径不同 |

## 4 三方结果对照（%）

| 数据集 | 模型 | 论文 | 官方仓库 | 本实现（末轮 / 验证最优） |
| --- | --- | --- | --- | --- |
| Cora | GCN | 81.5 | README 未给 | 80.63 ± 0.93 / 81.53 ± 0.70 |
| Cora | GAT | 83.0 | 84.4（单预训练权重） | 81.78 ± 0.65 / 82.00 ± 0.49 |
| Citeseer | GCN | 70.3 | 未提供 | 71.0 / 71.5（单种子） |
| Citeseer | GAT | 72.5 | 未提供 | 69.93 ± 0.61 / 69.97 ± 0.61 |
| Pubmed | GCN | 79.0 | 未提供 | 78.12 ± 0.53 / 78.64 ± 0.72 |
| Pubmed | GAT | 79.0 | 未提供 | 78.70 ± 0.41 / 78.77 ± 0.33 |

官方 README 的 84.4% 高于论文的 83.0%，说明单模型单次结果与多次运行均值之间波动可见，这也是本实现坚持多种子与双口径的原因。

## 5 结构对齐实验：输出层单头

| 输出层 | 参数量 | Cora（10 种子，末轮/验证最优） | Citeseer（3 种子） |
| --- | --- | --- | --- |
| 8 头（默认） | 95 536 | 81.78 ± 0.65 / 82.00 ± 0.49 | 69.97 ± 0.61 |
| 1 头（对齐官方） | 92 302 | 81.14 ± 0.55 / 81.21 ± 0.62 | 70.73 ± 0.33 |

方向相反：Cora 上单头低 0.64 点（末轮）／0.79 点（验证最优），逐种子配对差值 0.64 ± 0.876，t = 2.31（df = 9，临界 2.262），刚好越过 5% 显著性线，属边缘显著；Citeseer 上单头高 0.76 点。说明"对齐官方结构"不等于"精度提升"，头数应作为按数据集选择的超参。

复跑命令：

```bash
python gat.py --dataset cora --seeds 3 --out-heads 1
python gat.py --dataset citeseer --seeds 3 --out-heads 1
```

## 6 本实现相对论文与官方仓库的增量

多种子统计、末轮/验证最优双口径、MLP 基线（Cora 54.3%）、9 组 hidden×dropout 消融、Citeseer 边丢弃网格（最优 71.00 ± 0.25）、残差消融（负收益，已回滚）、按度数分层评估（GAT 仅在 6 度以上占优，11+ 度高 6.9 点）、注意力可视化（高度数邻居获 7–8 倍于均匀基线的权重）、纯 CPU 可运行（无需 TF1/CUDA/PyG）。

## 7 差异归因

| 差异项 | 方向 | 验证状态 |
| --- | --- | --- |
| 输出层头数 | 单头使 Cora −0.6~0.8 点、Citeseer +0.8 点 | 已验证（Cora 10 种子配对） |
| 测试口径 | 验证最优比末轮高 0.2–0.9 点 | 已验证 |
| 种子数 | 均值波动，标准差约 0.5 点 | 部分验证 |
| 注意力偏置 | 加偏置使 Cora 82.8→80.8 | 已验证 |
| 残差跳连 | Citeseer 69.03，负收益 | 已验证 |
| 稠密 vs 稀疏实现 | 数学等价，数值误差未知 | 未验证（无法跑 TF1） |
| dropout 施加次数 | 官方多丢一次变换后特征 | 未验证 |
| 官方预训练权重 | 84.4% 为单模型值 | 不可比 |

## 8 迁移时的等价性坑

1. `tf.nn.l2_loss(x)` = `∑x²/2`，而 PyTorch 的 `weight_decay` 按 `∑x²`；直接把 5e-4 传给优化器会让正则强一倍。
2. `tf.nn.dropout(x, keep_prob)` 的第二个参数是**保留率**，PyTorch 的 `p` 是**丢弃率**，数值恰好互换。
3. 稀疏 dropout 只丢非零项并缩放，稠密 dropout 会把零变非零，稀疏结构会被改变（期望一致）。
4. 官方用 N×N 稠密矩阵 + −1e9 掩码实现邻居 softmax；本实现用分组 max + 指数化 + 分组求和，内存从 O(N²) 降到 O(E)，这是能在 32 GB 内存机器上跑 Pubmed 的原因。

## 9 结论

1. GCN 差异仅在边角（偏置、dropout 形式、L2 范围、测试口径），主路径一致，Cora 差 +0.03 点，可视为复现成功。
2. GAT 差异是结构性的（单头输出、注意力偏置、验证最优口径），把输出层对齐官方后 Cora 反而降至 81.21，Citeseer 升至 70.73。
3. 价值在增量：把论文与官方都没提供的多种子、双口径、边丢弃、残差、度数分层与可视化补齐，使"为什么有差距"能落到实验上回答。
